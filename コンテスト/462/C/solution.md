```
3
2 1
1 3
3 2
```
のように出力が与えられる。
一番上がNで点の個数。
下はX Yの順で。

この中から、X、Yが両方ある点よりも大きい点の個数を除いた個数を出力しろ
XもYも自分より小さい点が出てきたら、それを保存する。

X座標でソートする
```
1 3
2 1
3 2
```
2 1を見る。2よりも前に、1よりも小さな点はないので大丈夫
3 2を見る。3 2よりも前にYが2よりも小さい点は1が存在してしまう。
Xはすでにソートされているので、XもYも小さい点が見つかった。
これをcountして、最後にN-countを出力すればOK

## 方針
1. Xでソート
2. for文で一つ一つ取り出し、min_yを超えたyを持つpointをcount
3. N - countを出力

### 1. Xでソート
普通にタプルのリストをsortするとXでソートされる。ちなみにsortのkeyに関数を渡せばYでもソートできる
### 2. for文で一つ一つ取り出し、min_yを超えたyを持つpointをcount
