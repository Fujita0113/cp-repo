実行時間制限: 5 sec / メモリ制限: 1024 MiB

配点: $2$ 点

### 問題文

$H$ 行 $W$ 列のマス目があります。上から $i \textrm{ } \left(\right. 1 \leq i \leq H \left.\right)$ 行目、左から $j \textrm{ } \left(\right. 1 \leq j \leq W \left.\right)$ 列目にあるマス $\left(\right. i , j \left.\right)$ には、整数 $A_{i , j}$ が書かれています。 すべてのマス $\left(\right. i , j \left.\right) \textrm{ } \left(\right. 1 \leq i \leq H , 1 \leq j \leq W \left.\right)$ について、以下の値を求めてください。

*   マス $\left(\right. i , j \left.\right)$ と同じ行または同じ列にあるマス（自分自身を含む）に書かれている整数をすべて合計した値

### 制約

*   $2 \leq H , W \leq 2000$
*   $1 \leq A_{i , j} \leq 99$
*   入力は全て整数

* * *

### 入力

入力は以下の形式で標準入力から与えられます。

$H$ $W$
$A_{1 , 1}$ $A_{1 , 2}$ $\hdots$ $A_{1 , W}$
$A_{2 , 1}$ $A_{2 , 2}$ $\hdots$ $A_{2 , W}$

$A_{H , 1}$ $A_{H , 2}$ $\hdots$ $A_{H , W}$

### 出力

マス $\left(\right. i , j \left.\right)$ と同じ行または同じ列にあるマス（自分自身を含む）に書かれている整数をすべて合計した値を $B_{i , j}$ として、以下の形式で出力してください。

$B_{1 , 1}$ $B_{1 , 2}$ $\hdots$ $B_{1 , W}$
$B_{2 , 1}$ $B_{2 , 2}$ $\hdots$ $B_{2 , W}$

$B_{H , 1}$ $B_{H , 2}$ $\hdots$ $B_{H , W}$

## 解く
	10^8くらいまでなら大丈夫らしいので、4×10^6のO(N^2)なら大丈夫だ
	まず配列を2つ作ってその中にそれぞれの行と列の和を入れる。
	そのあと、その値を引いたやつを2×2の行列の中に入れる。
	ただ、問題が合って、行列のつくりかたがわからん
```Python
N, M = 3, 3 
mat = [[0] * M for _ in range(N)]
```
AtCoderでよく使う入力パターンをまとめますね。

## 基本

```python
# 整数1つ: N
N = int(input())

# 整数2つ: N M
N, M = map(int, input().split())

# 文字列: S
S = input()
```
mapってmap(型, list)に対して型を当てつつタプルに変換して返しているって認識でOK？
→違う。イテレータっていってメモリに保存しない、一時的なリストみたいにして保存している。
例えば次みたいに一回printするともうなくなってしまう
```Python
m = map(int, ["1", "2", "3"])
print(list(m))  # [1, 2, 3]
print(list(m))  # []  ← もう空！
```
## リスト

```python
# 1行に複数の整数: 1 2 3 4 5
A = list(map(int, input().split()))

# N行に1つずつ
A = [int(input()) for _ in range(N)]

# N行に2つずつ: a b
AB = [list(map(int, input().split())) for _ in range(N)]
# a, b を別々に使いたいなら
# a, b = AB[i][0], AB[i][1]
```

## グリッド・行列

```python
# N×M の数値グリッド
grid = [list(map(int, input().split())) for _ in range(N)]

# 文字のグリッド（"..##.." みたいなやつ）
grid = [input() for _ in range(N)]

# 文字グリッドをリスト化（書き換えたい場合）
grid = [list(input()) for _ in range(N)]
```

## 高速入力（TLEしそうなとき）

```python
import sys
input = sys.stdin.readline

# あとは普通に input() を使うだけ
# ※文字列の場合は末尾に改行がつくので .strip() する
S = input().strip()
```

`sys.stdin.readline` に差し替えるだけで入力が速くなるので、入力量が多い問題ではとりあえず入れておくと安心です。
