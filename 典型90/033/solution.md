```
2 3
```
のように入力が与えられる。このとき、2×3の敷地が与えられて、2×2の範囲内に1つまでしかLEDを置けない条件で最大何個までLEDを置けるかを出力する。
この例の場合は
点灯している LED を '#'、消灯している LED を '.' とすると、たとえば以下の状態が、適切である中で点灯している LED の個数が最大となります。
```
#.#
...
```
となるので、2が正答になる。
## 考え方
行と列に分けて考える。仮に1行だったとして、H列あったとするよ。
1列だったら答えは1だ。
2列でも変わらず1
3列になったら#.#がいけるので2。
4列も2
5列が3
というように考えられ、行も同じように考えられる。
これをお互いかけ合わせれば答えが出る。

つまり、HeightとWidthを偶数だったら2で割った数、奇数なら2で割ってから1を足した数に変換し、かけるだけ

## 正答
問題文をよく読もう
このイルミネーションは、以下の条件を満たすとき **不適切である** といいます。

-   イルミネーション全体に完全に含まれる 縦 $2$ $\times$ 横 $2$ の、$4$ つの LED を含む領域であって、点灯している LED が領域内に $2$ つ以上あるものが存在する。

４つの領域を含む領域であってというところが重要。つまり、例えば1×5の領域が与えられたら2×2の領域は存在しないから答えは5になるのだ。
