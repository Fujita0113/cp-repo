```
2 2 3
```
のように入力が与えられる。これは2, 2, 3の直方体を表す。
これを何回切ったら全て立方体にできますか？って問題。
これは全部同じ立方体に分けるしかない。例えば1の立方体と2の立方体を両立させようとしたとして、１の部分を切ったら２の部分が絶対に分けられてしまうから。
また、これは例から気づきやすいようになっていた。

上の入力例の出力例は以下である
```
4
```
4 回ケーキを切断することで、一辺の長さが 1 の立方体が12 個できます。
次の出力例には「1 回ケーキを切断することで、一辺の長さが2 の立方体が2 個できます。」
って書いてあった。

## 解法
2, 2, 3の直方体に対して1は最大公約数である。
4はx, y, z, gcdとしたときに
4 = (x - gcd -1) + (y - gcd - 1) + (z - gcd - 1)
で表される。
