```
7
1 72
2 78
2 94
1 23
2 89
1 40
1 75
1
2 6
```
上のように入力が与えられて、1 72は1組の1番の生徒が72点を取ったという意味。次の2 78は2組の2番の生徒が、その次の2 94は2組の3番の生徒が...という感じ

それで、その次の2 6は1組の2番から6番の生徒の合計点数 2組の合計点数のように出力しなさいという指示

## 注意点
- forループの中で出力を組まない。
  - よくわからないけど、これによって時間がめちゃくちゃ掛かる可能性があるらしい。
  - 以下のようにして出力すればI/Oを一回で済ませられる
```Python
print("\n".join(answer))
```
- クラスと点数を2次元配列で受けるくらいなら、2つ1次元配列を使ったほうがわかりやすい
- 次のように[0] * N + 1だと配列に+1をするとみなされてしまい、エラーになるのでちゃんとかっこで囲うこと
  ```
  sum1 = [0] * (N + 1)
  ```
## 解き方
1. 入力を受ける
2. 累積和の配列を作る。ただしこのとき、[0]は0にすること。こうすることで1~xの番号の合計点数を求めろって言われたときに、[n]-[m-1]で全部求められる
3. ans配列を作る。f"{a} {b}"のようにすると、変数aとbの中身を取り出して、a bという文字列を作れるので、
   ```Python
   ans.append(f"{a} {b}")
   ```
    のようにするとよい
4. print("\n".join(ans))で出力する
