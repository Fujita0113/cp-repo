２つ２次元配列が与えられて、
2×2の正方形を+1もしくは-1するという操作の末にAとBを一致させられるならYes, できないならNoを出力し、更に最小回数も出力しなければいけない。

## 考える
左端から確定させればいいのではないかなと思う。
座標1, 1でAとBが違う場合、操作を1, 1で起動させる以外に1, 1の値を動かす方法はないのでそこから始める。
左の辺と上の辺からスタートして徐々に埋めていく感じ。
一回の操作はO(1)でできるし、ループはHW回、つまりは10000回で済む。
## 方針立てる
まずじゃあ0を指定するとします。
そしたら0, 0に対して例の操作を行います。
次に0, 1... W - 1 にも行います
その次に1... H - 1, 0にも行います。
じゃあ例の操作って何？
そこの座標のAとBを比べて差を出します。B-Aだね
その差分だけ、４つ足します。
```
def action(i, j, A, B, H, W):
    num = B[i][j] - A[i][j]
    for ni, nj in [(i, j), (i + 1, j), (i, j + 1), (i + 1, j + 1)]:
        if ni < H and nj < W:
            A[ni][nj] += num
    return A
for i in range(min(H, W)):
    action(i, i, A, B, H, W)
    for j in range(i + 1, H):
        action(j, i, A, B, H, W)
    for k in range(i + 1, W):
        action(i, k, A, B, H, W)
```
