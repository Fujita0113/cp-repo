## 繰り返し二乗法について
いい質問。繰り返し二乗法は競プロで一生使う道具なので、今日身につけてしまいましょう。

何がボトルネックだったか

for _ in range(N - 2):
    result = result * (K - 2) % NUM
$N = 10^{18}$ で $10^{18}$ 回ループ＝100京回の掛け算。1秒に $10^8$ 回くらいしか回らないので、宇宙が終わります。

やりたいのは $(K-2)^{N-2}$ を求めることだけ。N回掛けたいわけじゃない、結果が欲しいだけ。なら掛ける回数を減らせばいい。

繰り返し二乗法のアイデア
例として $3^{13}$ を求めたいとします。

普通にやると12回掛け算ですが、指数を2進数で見ると魔法が起きます。

$$13 = 8 + 4 + 1 = 1101_{(2)}$$

なので

$$3^{13} = 3^8 \cdot 3^4 \cdot 3^1$$

ここで $3^1, 3^2, 3^4, 3^8, \ldots$ は 「前の値を2乗する」だけで作れることに注目：

指数	値	作り方
$3^1$	3	元の値
$3^2$	9	$3^1 \times 3^1$
$3^4$	81	$3^2 \times 3^2$
$3^8$	6561	$3^4 \times 3^4$
つまり「2乗を繰り返して候補を作る」→「2進数の1が立っているところだけ掛け合わせる」の2ステップ。

$3^{13}$ なら $13 = 1101_{(2)}$ なので 1, 4, 8 のところで掛ける → $3 \times 81 \times 6561 = 1594323$。

掛け算の回数は $\log_2 N$ 回。$N = 10^{18}$ なら $\log_2(10^{18}) \approx 60$ 回。一瞬。

アルゴリズムに落とす
「指数を1ビットずつ右にシフトしながら、立っているビットのところで result に掛ける」を素直に書くだけ。


def power(base, exp, mod):
    result = 1
    base %= mod
    while exp > 0:
        if exp & 1:        # 一番下のビットが1なら
            result = result * base % mod
        base = base * base % mod   # baseを2乗（次の桁の準備）
        exp >>= 1          # 1ビット右シフト
    return result
具体値トレース（base=3, exp=13, modは大きいので無視）
ループに入る前：result=1, base=3, exp=13 (=1101)

イテレーション	exp（2進）	最下位ビット	resultへ掛ける？	更新後 result	更新後 base	更新後 exp
1回目	1101	1	する	$1 \times 3 = 3$	$3^2 = 9$	110 (=6)
2回目	110	0	しない	3	$9^2 = 81$	11 (=3)
3回目	11	1	する	$3 \times 81 = 243$	$81^2 = 6561$	1
4回目	1	1	する	$243 \times 6561 = 1594323$	(どうでもいい)	0
exp=0 でループ終了。result = 1594323 = 3^{13}。✓

イテレーションは4回（$\lceil \log_2 13 \rceil = 4$）。

あなたのコードに組み込む

N, K = map(int, input().split())
MOD = 10 ** 9 + 7

def power(base, exp, mod):
    result = 1
    base %= mod
    while exp > 0:
        if exp & 1:
            result = result * base % mod
        base = base * base % mod
        exp >>= 1
    return result

if N == 1:
    print(K % MOD)
elif N == 2:
    print(K * (K - 1) % MOD)
else:
    ans = K * (K - 1) % MOD * power(K - 2, N - 2, MOD) % MOD
    print(ans)
Pythonの便利関数
実は Python の組み込み pow は第3引数に mod を渡せて、内部で繰り返し二乗法をやってくれます。しかも C で書かれているので自前ループより速い。


power(K - 2, N - 2, MOD)
# は
pow(K - 2, N - 2, MOD)
# と書ける
なので最終的にはこれで十分：


N, K = map(int, input().split())

elif N == 2:
    print(K * (K - 1) % MOD)
else:
    print(K * (K - 1) % MOD * pow(K - 2, N - 2, MOD) % MOD)
ただし**「pow の中身は繰り返し二乗法」と知った上で使う**のが大事。中身を知らずに使うと、行列累乗とか別の問題で「なんで遅いんだろう」となります。

「N回繰り返す」ループで $N \geq 10^9$ を見たら → forループは諦める

2進数表現で分解すると掛け算が log 回で済む、というのが基本原理
