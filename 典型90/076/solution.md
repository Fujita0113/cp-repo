どうやら、連続する２つのピースじゃなくても１つでもいくつでもいいらしい
追っている連続ピースが1/10を超えた時点でbreakすればいいので、計算量は問題ないと思う。
ただ難しいのが、どうやってN-1番目の次を0番目にするかだね。
二番目のループをwhileにしてインデックスを自分で管理できるようにしたうえで、j == Nになったときに j = 0にすればいいだけの話なんだけどね。
```
for i in range(N):
    j = i
    S = 0
    while True:
        S += A[j]
        if S == piece:
            print("Yes)
            sys.exit()
        elif S > piece:
            break
        j += 1
        if j == N:
            j = 0
```
一番目のループではどこから数え始めるかを指定する。
二番目のループでは、pieceと一致したらprint, Sがpieceを超えたらbreak, jを更新してj == Nになったら初期化
