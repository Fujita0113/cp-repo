Nという数字が書かれたボールが一個ある。
ある操作を１回したとき、そのボールに素数が書かれていれば、ボールには何も起こらない。
素数が書かれていなければ、ボールはaとbと書かれたボール２個に分裂する。
a * b = xであり、a, b>=2である。ちなみにxがその時ボールに書かれていた数字。

全部素数にするまでにかかる最小の回数を教えろ
## 全体像を考える
まず素数を判定するための方法がわからないが、仮に素数チェック関数ができたとしてできるのか考える。
N=a^h * b^i * c^j
みたいな感じで素因数分解っていうんだっけ？できれば行けそうだよね。そしたらh+i+jが答えになる。多分最小とか言ってるけどどの経路だったとしても同じになると思うんだよね

じゃあPythonで素因数分解する方法がわかるかと言われるとすごく困るのだ。

1. Nを素因数分解する
2. 指数を足し算してprintする
### Nを素因数分解する
Nは10^12だから、forループはできないと一見思いがちだけれど、２で割ったら２の倍数はすべて素数じゃないからその後のループは奇数だけで行うことができる。でも半分になるだけだから5* 10^11になるだけ。
ループの後ろのほうの奇数を素因数の一つに含まれると多分落ちる。どうしたらいいのだろうか

## もう１回考える
答えはi + j + kじゃなくてlog2_(i+j+k)だった。すべてのボールを同時に叩くから。

ループは√Nまでで十分。仮にだよ？N = a * bとして表されたとする。a < √N < bだったとする。そしたら√Nまで回せばaは見つけることができる。
その次のループはN/aでやればいい。同様に√N/aまでで。
その場合、10^6 + 10^3 + ...になるので、余裕でループが回るはず。

なので、ループ部分を関数でまず作りたい。結局欲しいのはi+j+kだけだからcountだけreturnできればいいはず
1. ループ部分作る
2. logで答えを出す

### 1. ループ部分作る
```
Nを受け取る
count初期化
while True:
    √N以下でループ
        N % i == 0:
            count++
            N /= i
            break
    if N == 1:
        break
return count
```
そういやルートの出し方知らないや
math.sqrtでいいんだけど、
for i in range(少数)のときってどうなるんだろう。例えば2.5が入ったとして2までループ回るのかな
→入らない。int(2.5)で2になるから、それに1足すのが安牌かな

テストする。8なら2^3なので3になるはず
```
import math

def myFactorization(N):
    if N == 1:
        return 1
    count = 0
    while True:
        # 素数フラグ
        flag = True
        # ループの始まりについて
        # 1で割り切れるのは全部そうなので２からスタート

        # ループ上限について
        # 2.5だとしたら、2まではiが到達してほしい。intで2にしてからrange(3)にしている。
        # 4だとしたら、4まで回ってほしいのでどちらにせよOK
        for i in range(2, int(math.sqrt(N)) + 1):
            if N % i == 0:
                count += 1
                N //= i
                flag = False
                break
        # Nが2か3になると、√が1.いくつなので、for i in range(2, 2)になり、無限ループ
        if flag:
            count += 1
            break
        if N == 1:
            break
    return count
        
```
素数フラグを加えて作り直した。

### 3. 初めから素数だったときに1と出てしまうバグの修正
ループ外でTrueにして、内部ではTrueにならないようにした。これで大丈夫なはず
```
def myFactorization(N):
    if N == 1:
        return 1
    count = 0
    zero_flag = True
    while True:
        # 素数フラグ
        flag = True
        # ループの始まりについて
        # 1で割り切れるのは全部そうなので２からスタート

        # ループ上限について
        # 2.5だとしたら、2まではiが到達してほしい。intで2にしてからrange(3)にしている。
        # 4だとしたら、4まで回ってほしいのでどちらにせよOK
        for i in range(2, int(math.sqrt(N)) + 1):
            if N % i == 0:
                count += 1
                N //= i
                flag = False
                zero_flag = False
                break
        # Nが2か3になると、√が1.いくつなので、for i in range(2, 2)になり、無限ループ
        if flag:
            count += 1
            break
        if N == 1 and zero_flag:
            break
    return count
```
