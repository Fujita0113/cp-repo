### 2. 全部の桁を取り出して8があったら置換して戻す
9進数の中から8があったら5にするのをしたい。
convertNumで作る
まずforループで全部の桁の数をarrに放り込む。さらに放り込む前にif文で判定して8だったら5に変換する。
sum関数で足して返す
こんな感じで。動作確認済み
```
def convertNum(N):
    arr = []
    while True:
        if N % 10 == 8:
            arr.append(5)
        else:
            arr.append(N % 10)
        N = N // 10
        if N == 0:
            break
    return sum(arr[i] * (10 ** i) for i in range(len(arr)))
```

## 模範解答を理解したい
```
N, K = input().split()
K = int(K)
for _ in range(K):
    x = int(N, 8)              # 8進表記の文字列 → 10進整数
    s = ""                     # 9進表記の文字列を作る
    if x == 0:
        s = "0"
    while x:
        s = str(x % 9) + s
        x //= 9
    N = s.replace("8", "5")    # 8 を 5 に置換（次のループでは「8進表記」とみなされる）
print(N)
```
int関数を使うために、N, Kはmapでintに変換しないようにしている。
int関数の第一引数は文字列のみ

if x == 0で切り出しているのは、while x:と書いているせいで、xに0が入るとループ内部に入らずに終了してしまうから。while Trueでbreakすれば問題ない。
### x = int(N, 8)ってなんぞや？

```
x = int("10", 8)
```

## 模範解答を自力で出す
ループ内部でint(N文字列, 8)を使って8進数から10進数に変換して、文字列で9進数を作れれば早い。
9進数を文字列で扱えるのであれば、s = str(x % 9) + sのようにして、9で割った余りを前に付け足していくことができる。
さらにs.replace("8", "5")を用いれば配列を用いずとも置き換えが可能
