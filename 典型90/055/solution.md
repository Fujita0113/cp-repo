みたいに与えられて、1行目はNと割る数、あまり
2行目が配列
配列の中から任意の5つを選び、積を作る。それを割る数で割ってその余りがあまりになるケースは何ケース？って話

Nが100以下だから100C5を考えると10^8より小さいから全部網羅で行けそう。
でもどうやって網羅するん？って話はある。
PythonのCombinationsみたいな組み合わせを全部網羅できる関数があったようにおもうのでそれを使いたいが使い方がわからん
```
from itertools import combinations

# 使い方: combinations(iterable, r)
# iterable: 要素を取る対象（リストなど）
# r: 1回に取る要素数

items = [1, 2, 3, 4]
for combo in combinations(items, 2):
    print(combo)

# 出力:
# (1, 2)
# (1, 3)
# (1, 4)
# (2, 3)
# (2, 4)
# (3, 4)
```
## 解き方
普通に入力を受けてから、combinationsを使う。これを使うとタプルで括られたリストが返るはずだからforループに入れる
そしてタプルも中でforループに入れて、その中で全部かけて割って余りが一致したらcount++すれば良さそう
forループに入れるよりもmath.prodを使って、comboの中身をそのまま計算したほうが早そう
```
import math

# Python 3.8以降
result = math.prod((2, 3, 4))
print(result)  # 24
```
## 正答
math.prodを使うのではなく、余りを取りながら計算しないといけなかった。
多倍長整数という概念がある。これは、CPUは一回に2^64、つまり 10^18くらいまでしか扱えないということ。
これ以上になるとJavaなどではオーバーフローが起こる。
しかし、Pythonは無限の数を扱うことができる。
しかしそれでも2^64を超えると大幅に計算に時間がかかるようになってしまう。
なので (a * b * c * d * e) % Pにするのではなく、
((a % P) * b % P ...)のように常に余りを取りながら計算することでオーバーフローを防ぐことができる
