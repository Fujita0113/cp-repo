```
6
1 2
1 1
2 3
3 1
3 2
3 3
```
のように入力が与えられる。
一行目はQでここから先に何回操作が書かれているかが示されている。

2行目以降はtと数字の組み合わせ。
tは1のとき、数字の書かれたカードを山札の一番上に、2のとき一番下に置く。
3のときは山札の数字番目のカードに書かれた数値を出力しなければいけない。

## 解き方
デキューを使えばいける
```Python
from collections import deque

dq = deque()

# 後ろから追加
dq.append(10)
dq.append(20)

# 前から追加
dq.appendleft(5)
dq.appendleft(1)

# 状態: [1, 5, 10, 20]
# インデックス: 0, 1, 2, 3

# インデックスアクセスも可能
print(dq[0])  # → 1

# 前から削除
dq.popleft()  # → 1

# 後ろから削除
dq.pop()      # → 20
```
